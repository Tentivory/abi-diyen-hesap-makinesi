# Abi Diyen Hesap Makinesi

## Resmi Tanım (Ciddi)

Bu proje, insanlığın en büyük sorunlarından biri olan "abi demeden iş yaptıramama" krizine bilimsel ve matematiksel bir çözüm sunmaktadır. Yıllar süren araştırmalar, derin felsefi düşünceler ve sayısız fincan Türk kahvesi sonucunda ortaya çıkan bu algoritma, kullanıcının söylediği "abi" sayısına göre matematiksel işlemleri gerçekleştirir. Daha az abi demek, daha az doğru sonuç demektir. Bu bir bilimdir.

## Nasıl Çalışır (Abartılı)

1. Programı çalıştırın.
2. Ne kadar "abi" dediğinizi belirtin (rakam olarak).
3. İki sayı girin.
4. Program, abi sayısına göre sonuçu çarpıp, bölüp, abartarak verecektir.
5. Eğer yeterince abi demediyseniz, sonuç "daha sonra gel" olur.

## Kurulum

```bash
pip install hiçbir-sey
python abi_diyen_hesap_makinesi.py
```
